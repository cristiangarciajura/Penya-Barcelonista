Publicar a la web

  1. Prepara les notícies i prem Copiar JSON.
  2. Obre el fitxer de notícies a GitHub.
  3. Substitueix-ne el contingut pel JSON copiat i prem Commit changes.

Només les persones amb permís d'escriptura a GitHub poden publicar. Aquest editor no demana contrasenyes ni tokens. Les notícies es guarden provisionalment en aquest navegador fins que les publiques. La selecció de portada queda guardada al JSON; falta connectar-la amb la portada pública. Les fotografies adjuntades s’inclouen en el JSON exportat.
